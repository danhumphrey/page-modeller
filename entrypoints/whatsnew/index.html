Page Modeller

Version 3 is here

A complete rewrite, and the first thing to say is where everything went.

Where to find it

Side panel
Click the Page Modeller toolbar icon. This is new — in version 2 there was only DevTools.
DevTools
Press F12 and choose Page Modeller, exactly as before.
Options
Right-click the toolbar icon. Your existing settings have carried over.

What's new

  • Playwright, in TypeScript and Python, generating role- and label-based locators. Selenium WebDriver Python joins Java and C#.
  • Elements inside iframes. The frame an element lives in is part of its locator, so the generated code enters the frames to reach it — cross-origin, srcdoc and sandboxed frames included.
  • Elements inside shadow DOM. Web components keep their real controls in a shadow root, where an ordinary DOM search cannot see them. Page Modeller now scans into open shadow roots and generates locators that reach them.
  • A choice of output style per framework: a full page object, locators only, or — for Selenium — the methods Page Modeller has always generated.
  • Locators are checked as they are generated, and the eye shows you what one matches before you trust it — counted the way your chosen framework counts, which is not always the way the browser does.

Two things that have gone

  • Robot Framework and Protractor are no longer generated. Neither is maintained upstream.
  • Images no longer get a click method. Elements are classified by their accessibility role now rather than their tag, which is more accurate nearly everywhere — and means an <img> is treated as static unless it genuinely has a button role.
Everything still runs entirely in your browser: no network requests, no accounts, nothing leaves the page. Found a problem, or want a framework we do not generate? Let me know on GitHub.
