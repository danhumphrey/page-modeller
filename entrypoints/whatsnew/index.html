Page Modeller

Version 3 is here

A complete rewrite, with new functionality and modern framework and browser support.

Side panel
New - Click the Page Modeller toolbar icon to load Page Modeller in the browser side panel.
DevTools
Press the DevTools shortcut and use Page Modeller from the DevTools panel as before.
Options
Right-click the toolbar icon. Your existing settings have carried over.

What's new

  • Playwright, in TypeScript and Python, generating role- and label-based locators. Selenium WebDriver Python joins Java and C#.
  • Elements inside iframes. The frame an element lives in is part of its locator, so the generated code enters the frames to reach it.
  • Elements inside shadow DOM. Web components keep their real controls in a shadow root, where an ordinary DOM search cannot see them. Page Modeller now scans into open shadow roots and generates locators that reach them.
  • Alternate code generation styles per framework and language generate a full page object, methods or just the locators.
  • Framework aware locators and match validation within the browser - the way the framework locates elements, not the browser.

Removed

  • Robot Framework and Protractor are no longer generated. Neither is maintained upstream.
Everything still runs entirely in your browser: no network requests, no accounts, nothing leaves the page. Found a problem, or want a framework we do not generate? Let me know on GitHub.
